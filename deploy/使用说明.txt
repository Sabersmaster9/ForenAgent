========================================================================
  ForenAgent 1.0  鉴定意见书生成系统  ——  安装与使用说明
========================================================================

本安装包全程离线，目标电脑不需要联网，也不需要安装 Python、conda
或任何开发工具。


------------------------------------------------------------------------
 一、安装包内容
------------------------------------------------------------------------

  app\                 程序本体（代码 + 量角器视觉模型 + OCR 模型缓存）
  env.zip.part00       Python 运行环境的分卷（共 3 卷，安装时自动合并）
  env.zip.part01
  env.zip.part02
  ollama_models\       本地大模型 qwen3.5:4b（约 3.4 GB）
  OllamaSetup.exe      本地大模型服务 Ollama 的 Windows 安装程序（约 180 MB）
  安装.bat             安装程序（双击运行一次）
  启动ForenAgent.bat   日常启动入口
  使用说明.txt         本文件

  说明：环境包拆成 3 卷，是因为 U 盘多为 FAT32 格式、单文件不能超过 4 GB。
        安装.bat 会自动把它们拼回完整文件，你不需要手动处理。


------------------------------------------------------------------------
 二、安装步骤
------------------------------------------------------------------------

【第 1 步】拷贝

  把整个「ForenAgent_部署包」文件夹拷到 U 盘，再拷到目标电脑的固定位置。
  建议放在 D 盘根目录，并且**把文件夹改名为纯英文**，例如：

      D:\ForenAgent\

  为什么要注意英文名：Paddle 的 C++ 推理层用窄字符 API 打开模型文件，路径里
  只要有中文就打不开，结果是所有照片 OCR 全部失败（而 PDF 因为有文字层走文本
  抽取、不经过 OCR，看起来"只有一个文件成功"），非常容易被当成显卡问题。
  新版启动脚本已经把模型缓存自动搬到 %ProgramData%\ForenAgent 下规避了这一点，
  但仍建议整个目录都用英文名，省得再踩到别的库。

  注意：
   · 目标盘至少需要 15 GB 可用空间
   · 拷完后请核对文件数量与大小，特别是三个 env.zip.part0x 分卷
     必须都拷全（缺任意一卷，安装会失败）

【第 2 步】运行安装程序

  双击「安装.bat」，按提示确认。它会自动：
     1. 合并分卷并解压，释放 Python 环境
     2. 配置运行环境
     3. 校验程序文件是否完整
     4. 在桌面创建快捷方式「ForenAgent 鉴定意见书生成」

  预计 5-10 分钟（含合并与解压约 9 GB 内容）。

【第 3 步】安装本地大模型（全程离线，只做一次）

  3.1  双击本安装包里的「OllamaSetup.exe」，按提示装完即可，不需要联网。
       装完后右下角托盘会出现灰色羊驼图标。

       注意：不要用 Ollama 官网给的
           irm https://ollama.com/install.ps1 | iex
       那行命令是给 Linux/macOS 用的，Windows 上装的应该是 OllamaSetup.exe。

       （万一安装包里没有这个文件，再自行到 https://ollama.com/download
         下载 Windows 版。）

  3.2  把本安装包里 ollama_models 文件夹下的两个子文件夹，
       覆盖拷贝到下面这个位置：

           C:\Users\<你的用户名>\.ollama\models\

       拷完后目录结构应该是：

           .ollama\models\blobs\sha256-81fb60c7...
           .ollama\models\manifests\registry.ollama.ai\library\qwen3.5\4b

       注意：如果 .ollama\models 已存在其它模型，直接覆盖合并即可，
             不会影响原有模型。

  3.3  验证：打开命令行（Win+R 输入 cmd 回车），执行

           ollama list

       能看到 qwen3.5:4b 就成功了。


------------------------------------------------------------------------
 三、日常使用
------------------------------------------------------------------------

  1. 确认桌面右下角托盘里有 Ollama 图标（灰羊驼）。
     没有的话，从开始菜单启动一次 Ollama。

  2. 双击桌面「ForenAgent 鉴定意见书生成」。

  3. 在弹出的界面里：
       第 1 步  点「选择案件材料文件夹」，选中本案的证据材料文件夹
       第 2 步  点「选择检查照片文件夹」（没有检查照片可跳过）

  4. 点「▶ 运行所选案件」，按提示完成几个确认窗口。

  5. 完成后点「打开输出目录」，结果在你所选文件夹内的「输出」子目录：

        鉴定意见书.docx     可直接交付的正式文书
        鉴定意见书.md       同一份正文
        AI审计报告.md       人工审查项与存疑点汇总


------------------------------------------------------------------------
 四、常见问题
------------------------------------------------------------------------

【安装时提示分卷合并失败】
   三个 env.zip.part0x 没拷全，或拷贝中断。请重新拷贝这三个文件，
   并核对大小：part00 与 part01 各约 2.34 GB，part02 约 0.15 GB。

【双击图标后闪一下就没了】
   说明环境有问题。改为双击「启动ForenAgent.bat」，
   它会停在出错画面上并显示原因，把整个窗口截图发给技术人员。

【启动时提示"图形界面组件（Tcl/Tk）加载失败"】
   说明 Python 运行环境解压不完整或库目录没被正确识别。
   先确认这个文件存在： env\Library\lib\tcl8.6\init.tcl
   不存在就重新运行「安装.bat」；存在但仍报错，请把整个窗口截图给技术人员。

【提示"未检测到本地大模型服务"】
   Ollama 没启动。从开始菜单启动 Ollama，等托盘出现羊驼图标后重试。

【OCR 很慢】
   正常。本机若无独立显卡，文字识别走 CPU，一个案件可能需要几分钟。

【想换更大的模型（如 qwen3.5:9b）】
   目标电脑有 16 GB 显存，可以再装一个：
       ollama pull qwen3.5:9b
   然后在界面「模型调用」页点「刷新已装模型」，
   在下拉框里选择即可。两个模型可以共存，随时切换。
   注意：9b 更慢，抽取质量是否更好需要用实际案件对比后再决定。
